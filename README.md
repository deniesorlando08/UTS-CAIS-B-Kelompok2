# Collaborative Academic Information System (CAIS)

## 1. Deskripsi Proyek

Collaborative Academic Information System (CAIS) merupakan
website sederhana yang dikembangkan sebagai proyek UTS
mata kuliah Collaborative Computing.

Proyek ini dibuat secara kolaboratif oleh tiga anggota
kelompok dengan memanfaatkan Git dan GitHub sebagai
version control dan media kolaborasi pengembangan.

## 2. Tujuan Proyek

- Menerapkan konsep kolaborasi dalam pengembangan perangkat lunak.
- Memahami penggunaan Git dan GitHub.
- Menerapkan branching, commit, push, pull, dan merge.
- Melakukan Pull Request dan Code Review.
- Mengembangkan aplikasi web secara berkelompok.

## 5. Fitur Aplikasi

1. Login
   - Form username dan password.
   - Validasi input.
   - Navigasi ke Dashboard.

2. Dashboard
   - Halaman utama aplikasi.
   - Informasi jumlah mahasiswa.
   - Navigasi ke Data Mahasiswa.
   - Tombol Logout.

3. Data Mahasiswa
   - Menampilkan daftar mahasiswa.
   - Form tambah mahasiswa.
   - Informasi NPM, nama, dan program studi.

## 7. Branching Strategy

Branch yang digunakan:

- main
- feature-login
- feature-dashboard
- feature-mahasiswa

Setiap anggota mengembangkan fitur pada branch masing-masing.
Perubahan kemudian diajukan melalui Pull Request untuk
dilakukan review sebelum digabungkan ke branch main.

## 8. Cara Menjalankan Aplikasi

1. Clone repository:
   git clone https://github.com/deniesorlando08/UTS-CAIS-B-Kelompok2.git

2. Masuk ke folder proyek:
   cd UTS-CAIS-B-Kelompok2

3. Buka folder menggunakan Visual Studio Code.

4. Jalankan file berikut melalui browser:
   pages/login.html
